# Семейный диспетчер

**ИИ, который занимается домашними делами.** Не ещё один список задач, а автономный диспетчер: слушает семью, извлекает дела, справедливо распределяет их между членами семьи, напоминает и перераспределяет просроченное.

Проект команды в акселераторе **Sber500 x Disrupt**.

---

## Проблема

До 60% семей тратят 2–3 часа в неделю на координацию быта. Этот «невидимый труд» почти всегда лежит на одном человеке и незаметно выжигает вечера и выходные.

Существующие продукты (Cozi, OurHome, FamCal, семейные календари) автоматизируют **хранение** задач. Ввод и распределение остаются ручными — поэтому нагрузка на «главного координатора» не снижается, а растёт. Мы автоматизируем сам труд координации.

## Как это работает

```
Услышать  →  Понять  →  Распределить  →  Напомнить  →  Проконтролировать  →  Перераспределить
```

- **Услышать** — голосовое сообщение, пересланный текст из чата, фото записки, событие из календаря
- **Понять** — GigaChat через function calling превращает свободную речь в структурированную задачу
- **Распределить** — детерминированный планировщик считает справедливость и выполнимость, GigaChat объясняет решение человеческим языком
- **Напомнить** — адаптивное время и тон под конкретного человека
- **Проконтролировать** — отслеживание выполнения, эскалация
- **Перераспределить** — просроченная задача уходит тому, кто сейчас свободен — без выяснения отношений

### Индекс невидимого труда

Система считает и показывает, сколько задач и часов фактически несёт каждый член семьи. Невидимый труд становится измеримым — этого нет ни у одного конкурента.

## Архитектура

```text
Голос / чат / календарь
        |
        +-- Flutter app
        +-- React-дашборд
        +-- Алиса / SberBoom
                |
                v
         FastAPI (backend)
        /       |        \
       v        v         v
TaskExtractor  Allocator  Reminder service
 (GigaChat)   (правила +   (Celery + Redis)
              справедливость)
        \       |        /
         \      |       /
          v     v      v
     PostgreSQL+pgvector   Redis
```

Ключевое архитектурное решение: **LLM не планирует расписание**. GigaChat отвечает за понимание языка и коммуникацию, справедливость распределения считает детерминированный алгоритм. Благодаря этому решение воспроизводимо, объяснимо и не «галлюцинирует» время.

Подробнее — [`docs/architecture.md`](docs/architecture.md).

## Технологический стек

**AI:** GigaChat API с function calling, GigaChat Embeddings + pgvector, SaluteSpeech / GigaAM для распознавания речи, OR-Tools в движке распределения

**Backend:** Python 3.12, FastAPI, Pydantic v2, SQLAlchemy 2.0, Alembic, Celery + Redis, PostgreSQL 16

**Клиенты:** Flutter (iOS + Android), React 18 + TypeScript + Vite + Tailwind CSS

**Инфраструктура:** Cloud.ru, Docker, Nginx, GitHub Actions, Prometheus + Grafana, Sentry

**Соответствие:** 152-ФЗ, хранение и обработка персональных данных на территории РФ

## Быстрый старт

Нужны Python 3.12+ и Node.js 20+. Без ключа GigaChat работает резервный разбор правилами.

```bash
git clone https://github.com/22129734/family-dispatcher.git
cd family-dispatcher

# Backend
cd backend
python -m venv .venv && source .venv/bin/activate    # Windows: .venv\Scripts\activate
pip install -r requirements-dev.txt
cp ../.env.example .env        # GIGACHAT_CREDENTIALS — по желанию
uvicorn app.main:app --reload  # http://localhost:8000/docs

# Web (в другом терминале)
cd web
npm install
npm run dev                    # http://localhost:5173, /api проксируется на :8000
```

Открывайте с телефона в той же сети: `npm run dev` печатает адрес вида `http://192.168.x.x:5173`.
Голосовой ввод в браузере требует HTTPS (или localhost).

**Один процесс для деплоя:** `npm run build` в `web/`, затем `uvicorn app.main:app` —
backend сам отдаёт собранный клиент из `web/dist`.

Тесты и линтер:

```bash
cd backend && pytest && ruff check .
```

### Что умеет MVP

- Создать семью и пригласить близких по ссылке (`/join/<код>`), без паролей
- Надиктовать или написать дело → задача извлекается и сразу распределяется
- Лента «Просрочено / Сегодня / Завтра / Позже / Без срока / Сделано», фильтр «Мои»
- Отметить сделанным, передать в один тап (вето), назначить вручную, поставить срок
- Повторяющиеся дела: после выполнения ставится следующее
- Индекс невидимого труда за неделю
- Продуктовые события и `GET /api/v1/analytics/daily` — DAU и действия на DAU (метрики Sber500)

## Дорожная карта MVP

Шесть недель от идеи до работающего продукта в руках реальных семей.

1. **Исследование** — не менее 20 интервью с семьями, архитектура, прототип. Метрика: не менее 8 интервью подтверждают проблему
2. **Ядро** — backend, мобильное приложение, дашборд. Метрика: задача создаётся и видна всей семье
3. **Интеллект** — GigaChat: извлечение задач и распределение. Метрика: точность извлечения не менее 85% на golden-set
4. **Цикл** — трекинг, push, перераспределение, Алиса/SberBoom. Метрика: не менее 70% задач проходят цикл автоматически
5. **Бета** — закрытый тест с 10–20 семьями. Метрика: не менее 60% назначений принимаются без правки
6. **Запуск** — доработка, лендинг, публикация. Метрика: не менее 100 в вейтлисте, не менее 40 активных семей

# План работ по MVP

Шесть недель от идеи до работающего продукта в руках реальных семей.

Работаем недельными спринтами: планирование в понедельник, ежедневные 15-минутные стендапы, демо и ретро в пятницу. Весь код в едином репозитории, разработка через pull request с обязательным ревью.

---

## Неделя 1 — Исследование и фундамент

- 10–12 глубинных интервью с целевыми семьями: группа А — дети школьного возраста, группа Б — пожилые родственники в семье
- Формализация JTBD, карта сценариев, приоритизация функций по RICE
- Архитектура системы, схема данных, дизайн API
- Кликабельный прототип ключевого сценария в Figma

**Артефакт:** подтверждённый скоуп MVP и прототип
**Метрика:** ≥8 интервью подтверждают проблему координации

---

## Неделя 2 — Ядро продукта

- Backend: FastAPI, модель данных «семья / участник / задача / расписание», аутентификация, приглашение в семью по ссылке
- Мобильное приложение на Flutter: онбординг, экран «сегодня», список задач, ручное создание задачи
- Веб-дашборд: базовый календарь семьи
- CI/CD и деплой на Cloud.ru

**Артефакт:** работающий сквозной каркас
**Метрика:** задача создаётся и видна всем членам семьи

---

## Неделя 3 — Интеллект: GigaChat

- Извлечение задач из текста и голоса: GigaChat function calling + SaluteSpeech
- Движок распределения: профиль загруженности, весовая модель справедливости, объяснение назначения
- Генерация персонализированных напоминаний
- Сборка golden-set и первые замеры точности

**Артефакт:** сценарий «надиктовал — получил распределённый план»
**Метрика:** точность извлечения задачи ≥85% на golden-set

---

## Неделя 4 — Замыкание цикла

- Трекинг выполнения, эскалации, автоматическое перераспределение просроченных задач
- Push-уведомления (FCM / APNs), утренний дайджест
- «Индекс невидимого труда»: расчёт и еженедельный отчёт семье
- Интеграция с календарями и навык для Алисы

**Артефакт:** полный цикл диспетчеризации без участия человека
**Метрика:** ≥70% задач проходят цикл автоматически

---

## Неделя 5 — Бета с реальными семьями

- Закрытый бета-тест с 5–7 семьями, ежедневный сбор обратной связи, продуктовая аналитика
- Замер гипотез H1–H4, разбор кейсов отказа от назначения
- Приоритизированный бэклог доработок

**Артефакт:** отчёт по гипотезам на реальных данных
**Метрика:** ≥60% назначений принимаются без правки, DAU/WAU беты ≥40%

---

## Неделя 6 — Полировка и запуск

- Доработки по итогам беты, стабилизация, оптимизация стоимости LLM-вызовов
- Лендинг с набором в вейтлист, публикация сборки в RuStore
- Подготовка демо и питча, финальные метрики

**Артефакт:** публично доступный MVP
**Метрика:** ≥100 семей в вейтлисте, ≥20 семей активны в продукте

---

## Гипотезы, которые проверяем

| | Гипотеза | Метрика успеха |
|---|---|---|
| **H1** | Семьи готовы отдать распределение задач алгоритму | ≥60% назначений принимаются без ручной правки |
| **H2** | Голос и чат снимают барьер ввода | ≥70% задач создаются не через ручную форму |
| **H3** | Продукт удерживает | Week-4 retention ≥30% (медиана по рынку 8–12%) |
| **H4** | «Индекс невидимого труда» вовлекает второго родителя | ≥50% семей имеют двух и более активных участников |

## Риски и способы их снять

| Риск | Как снимаем |
|---|---|
| Приватность семейной переписки | Никакого фонового чтения: только явная пересылка или opt-in. Храним задачу, а не текст |
| Конфликтность назначений | Право вето в один тап, объяснение каждого назначения, общий видимый баланс нагрузки |
| Холодный старт | Библиотека готовых семейных рутин, подключаемых в один тап |
| Стоимость LLM-вызовов | Кэширование, батчинг, маршрутизация на Lite, правила для повторяющихся задач |
| Нет опыта запуска B2C с высоким трафиком | Ментор по росту B2C в России — основной запрос к программе |

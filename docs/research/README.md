# Исследование: поиск целевой персоны и её проблемы

**Цель этапа:** по итогам 20+ интервью определить целевую персону и проблему в организации семейной жизни, которую будем решать. Методика — «Спроси маму» (Роб Фитцпатрик): говорим о прошлом опыте человека, а не о нашей идее.

Сценарий интервью — [interview-guide.md](interview-guide.md).

**Проведено 21 интервью** (01–04.10.2026): 15 живых с записью и 6 письменных в мессенджере.

> **Сырые данные не публикуются.** Записи, расшифровки и карточки респондентов хранятся у команды вне репозитория. Здесь — только обезличенные выводы.

4. Даже у человека с системой (календарь, CRM, заметки, холодильник) — хаос: инструменты разрознены, семейная рутина в них не попадает.
5. Мессенджер здесь не главный канал: с женой — устно и через холодильник.

# Исследование: поиск целевой персоны и её проблемы

**Цель этапа:** по итогам 20+ живых интервью определить целевую персону и проблему в организации семейной жизни, которую будем решать. Методика — «Спроси маму» (Роб Фитцпатрик): говорим о прошлом опыте человека, а не о нашей идее.

Сценарий интервью — [interview-guide.md](interview-guide.md).

> **Персональные данные в репозиторий не кладём.** Записи, расшифровки, карточки с цитатами и сводная таблица лежат локально в `D:\Projects\Sber500\Интервью\`. Здесь — только обезличенные выводы.

---

## Процесс

1. **Интервью** 30–40 мин, вживую или по видеосвязи, с записью на диктофон. Согласие на запись — в начале, на записи.
2. **Расшифровка** — положить файл в папку `Интервью` и запустить скрипт (ниже).
3. **Карточка респондента** — по расшифровке: сегмент, кто организатор, как передаются задачи, последний срыв, частота, текущие решения, время и деньги, главная боль дословно, интенсивность 1–5, сигналы интереса.
4. **Сводная таблица** `Интервью_сводная.xlsx`: лист «Респонденты» (строка на человека, выпадающие списки) и лист «Гипотезы» (за/против по номерам интервью).
5. После каждых 3–5 интервью — пересмотреть гипотезы; после 20+ — выбрать персону.

## Расшифровка

Локально, записи никуда не отправляются: `faster-whisper`, модель `large-v3-turbo`, CPU, int8. ~5 мин на 11-минутную запись (Ryzen 7 7735HS). Уже расшифрованные файлы пропускаются.

```bash
cd research
python -m venv .venv && .venv\Scripts\activate
pip install -r requirements.txt
python transcribe.py "D:/Projects/Sber500/Интервью"
```

Результат: `Интервью/Транскрипты/<имя файла>.md` с таймкодами `[мм:сс]`. Форматы: mp3, m4a, wav, ogg, opus, aac, mp4, mov, webm, mkv. ffmpeg не нужен.

Особенности:
- В скрипте звук декодируется через PyAV вручную: `faster-whisper` 1.2.1 передаёт в `av.open` параметр `metadata_errors`, которого нет в PyAV 19.
- Модель (~1,6 ГБ) скачивается с Hugging Face при первом запуске. На Windows без режима разработчика будет предупреждение про symlink — его можно игнорировать.
- Разделения по говорящим нет. Ошибки распознавания в основном в названиях («Валберес», «Гуваново»).
- Альтернатива для русского языка — GigaAM от Сбера (точнее, но нужен torch и ffmpeg).

| Условие попробовать | Не менять привычку: надиктовал → подтвердил | — |

**Наблюдения (n=2, не выводы):**
1. Оба — мужчины, не главные организаторы. **Нужны интервью с организаторами** (в первую очередь жёны Р1 и Р2).
2. Справедливое распределение дел как проблема не прозвучало.
3. Звучит контроль выполнения: срывы поручений, обязанности и уроки ребёнка.
4. Задачи живут в мессенджерах; семейными приложениями не пользуются.

## Замечания к технике интервью

Что исправить по итогам первых двух:
1. **Не продавать в конце** — вместо «готов попробовать, если выкатим?» спрашивать «можно вернуться, когда будет что показать?» и «с кем ещё поговорить?».
2. **Не подсказывать ответ** («может, проблем нет?») — выдерживать паузу.
3. **Копать в сильные истории** — «как часто? сколько времени? что пробовали? когда было последний раз?».
4. **Держаться темы** — не уходить в обсуждение инструментов и подписок.
5. **Согласие на запись** — в начале, на записи.
6. **Рекомендации знакомых** в конце каждого интервью — главный источник следующих респондентов.

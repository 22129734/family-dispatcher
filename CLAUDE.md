## Команды

```bash
cd backend && pytest && ruff check . && ruff format --check .   # тесты и линтер
cd backend && uvicorn app.main:app --reload                     # API :8000, /docs
cd web && npm run dev                                           # клиент :5173
cd web && npm run build                                         # tsc + сборка в web/dist
```

## Правила

- Язык интерфейса, документации, докстрингов и комментариев — русский.
- Сценарий продукта — «поручила — сделано»: задача уходит второму взрослому (`family_service.default_assignee`), исполнитель отвечает «Беру» / «Не могу», затем «Сделано». Движок «справедливого» распределения и индекс невидимого труда удалены — гипотеза не подтвердилась (0 из 20 интервью). LLM только разбирает текст в задачу.
- Код должен работать без `LLM_API_KEY` (резервный разбор правилами); тесты не ходят в сеть. LLM — OpenAI-совместимый API программы (Cloud.ru Foundation Models).
- Каждый вызов компонента (LLM, навык, голос, push, боты, фоновые задачи) логируется через `telemetry.track_call` / `telemetry.record` — это «обращения» по Положению конкурса (прил. 2, п. 2.2).
- Каждое пользовательское действие пишет событие через `family_service.track` — на этом считаются DAU и «обращения на DAU», метрики номинаций.
- Персональные данные респондентов (записи, расшифровки, цитаты с именами) в репозиторий не коммитить — репозиторий публичный. Они лежат в `D:\Projects\Sber500\Интервью\`.
- Новые зависимости бэкенда — в `backend/requirements.txt`; инструменты исследования — в `research/requirements.txt`.
